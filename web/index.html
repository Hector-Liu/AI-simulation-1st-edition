Experiment ID
Why is every prompt checked for banned words?

The study asks whether a shared label emerges from pairwise interaction alone. Words such as agree, coordinate, consensus, majority, most, the group would tell agents what to do or reveal group-level information, and reward words (points, score, win) would leak an incentive into the no-reward arm. Either would turn "emergence" into instruction-following. Before a prompt is sent, it is scanned; any hit stops the run and is written to leakage_report.json, which serves as audit evidence for SPEC §7.6 item 6.
